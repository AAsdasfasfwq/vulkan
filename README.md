# KRAKATOA 1883 — процедурный документальный фильм (Three.js + Web Audio)

Видео ~14,5 минут по сценарию `кракатау.json` (транскрипт Whisper вашей озвучки `кракатау.mp3`).
Вся картинка и весь звук генерируются кодом: никаких стоковых видео, фото и сэмплов.
Рендер — 1920×1080, 30 fps, MP4 (H.264 + AAC) для YouTube.

## Что внутри

- **298 планов**, каждый привязан к словам диктора по таймкодам Whisper (план меняется ровно на нужной фразе).
- **11 3D-локаций**: Зондский пролив с островом Кракатау, вулканом и кораблями, разрез вулкана (2.5D),
  магматическая камера, глобус, викторианский город, Батавия и Нью-Йорк, берег Явы с деревнями и маяком Анжер,
  интерьеры (веранда, телеграф, кабинет), машинный зал, поля с железной дорогой, морское дно, «студия» для 3D-инфографики.
- **2D-инфографика** в стиле kinetic typography: карты (Natural Earth), счётчики, диаграммы, сравнения
  (децибелы, мегатонны, высота волны, температура, жертвы и т. д.).
- **Хронологические плашки** («100 YEARS BEFORE», «1 HOUR BEFORE», «THE ERUPTION»…) — чистый текст на чёрном фоне
  с отдельным звуковым ударом.
- **Паузы в озвучке** для взрывов: 3 с — первый взрыв, 5,5 с — главный взрыв (огненный купол, ударная волна),
  2,5 с — удар цунами. Голос автоматически сдвигается, субтитры и планы тоже.
- **Звук на Web Audio**: ~100 процедурных эффектов, фоновые атмосферы, процедурная музыка, приглушение под голос.
  Громкость: голос ≈ −16 LUFS, эффекты и музыка на ~11 LU тише (не громко).
- Субтитры короткими фразами внизу кадра (можно отключить).

## Установка

Нужны **Node.js 20+** и **Google Chrome** (или Chromium). ffmpeg ставится автоматически (`ffmpeg-static`).

```bash
npm install
```

## Предпросмотр в браузере

```bash
npm run dev
```

Откройте адрес, который покажет Vite (обычно http://localhost:5173).
Кнопка Play / пробел — воспроизведение с озвучкой и звуком, ← / → — перемотка на 2 с, ползунок — перемотка.
Параметры адреса: `?t=440` — начать с 440-й секунды, `?scale=1` — полное разрешение (по умолчанию 0.5),
`?subs=0` — без субтитров. Звуковое оформление рендерится в фоне 1–3 минуты после первого нажатия Play.

## Рендер видео

```bash
node render.js
```

Результат: `out/krakatoa.mp4` (1920×1080, 30 fps). Скрипт сам собирает проект (Vite), открывает headless Chrome
через Puppeteer, рендерит кадр за кадром (каждый кадр — чистая функция времени, поэтому лагов и пропусков нет),
параллельно рендерит звук, затем склеивает голос с паузами, эффекты и видео через ffmpeg.

Полезные опции:

| Опция | Что делает |
|---|---|
| `--start 430 --end 460` | рендер только части (секунды итогового видео) |
| `--scale 0.5` | быстрый черновик 960×540 (`npm run render:preview`) |
| `--workers 3` | несколько окон браузера параллельно (быстрее на сильных ПК) |
| `--no-subs` | без вшитых субтитров |
| `--chrome "C:\Program Files\Google\Chrome\Application\chrome.exe"` | использовать установленный Chrome |
| `--headful` | показать окно браузера (на некоторых видеокартах Windows только так включается аппаратный WebGL) |
| `--angle d3d11` / `--angle vulkan` / `--angle gl` | выбрать графический бэкенд Chrome |
| `--crf 16 --preset slow` | качество H.264 (меньше crf — выше качество) |
| `--quality 0.93` | качество JPEG-кадров, передаваемых в ffmpeg |
| `--msaa 4` | сглаживание (0 — выключить, быстрее) |
| `--voice-gain 13.5` / `--sfx-gain 1.0` | громкость голоса (дБ) и эффектов (множитель) |
| `--reuse-audio` | не рендерить звук заново, взять `out/.render-tmp/sfx.wav` |
| `--skip-audio` | видео без звука |
| `--keep-tmp` | не удалять промежуточные сегменты |
| `--out путь.mp4` | куда сохранить |

### Скорость и видеокарта

В начале скрипт печатает `WebGL renderer`. Если там `SwiftShader` / `llvmpipe` / `software` — Chrome рисует
на процессоре, это очень медленно. Решения:

- Windows: `node render.js --chrome "C:\Program Files\Google\Chrome\Application\chrome.exe" --angle d3d11`,
  если не помогло — добавьте `--headful`.
- Linux: `--angle vulkan` или `--angle gl`.
- На хорошей видеокарте один воркер даёт порядка 3–8 кадров/с; полный фильм (26 115 кадров) —
  примерно 1–3 часа. `--workers 2..4` ускоряет, если хватает видеопамяти.

Сначала имеет смысл сделать черновик: `npm run render:preview` или кусок `--start 438 --end 452` (главный взрыв).

## Структура

```
render.js              рендер видео (Puppeteer → ffmpeg)
index.html, src/main.js точка входа, плеер предпросмотра и API рендера (window.KRAKATOA)
src/core/              таймлайн, привязка к словам (transcript.js), камера, движок, пост-эффекты
src/world/             небо, океан, остров, извержение и частицы, корабли, люди, здания, растения
src/sets/              3D-локации
src/overlay/           2D-инфографика, карты, плашки, субтитры
src/shots/act1…act8.js список планов по актам (что, где и на каком слове)
src/audio/             синтез звука, эффекты, атмосферы, музыка, офлайн-микшер
public/media/          озвучка и транскрипт
tools/                 служебные скрипты (снимки кадров, рендер только звука)
```

Чтобы поменять момент смены плана, правьте фразы в `src/shots/actN.js`: `A.at('фраза')` — время начала фразы в озвучке.
Паузы для взрывов задаются в `src/core/transcript.js` (`GAPS`).
